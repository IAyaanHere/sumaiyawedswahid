# Sumaiya with Wahid — Nikah Invitation

This repository contains the customized frontend assets for the Nikah & Nikah Dinner Invitation website of **Sumaiya Siddiqui with Wahid Patel**.

## Event Details
- **Date**: Thursday, 07th January 2027
- **Nikah**: Jama Masjid, Papdy, Vasai (After Namaz-e-Asr)
- **Guest Arrival**: Samaj Unnati Mandal, Manikpur, Vasai (07:00 PM)
- **Nikah Dinner**: Samaj Unnati Mandal, Manikpur, Vasai (08:00 PM / 07:00 PM – 10:00 PM)
- **Background Music**: `shukran-laka-rabbi.mp3`

## How to Deploy
1. Push to your GitHub repository (`https://github.com/IAyaanHere/sumaiyawedswahid.git`).
2. Import the repository into [Vercel](https://vercel.com).
3. Vercel will automatically detect and serve it as a high-performance static website with zero build configuration needed.
